# Articulated limb intermediate

New rounded upper arms, forearms, hands with held instruments, upper legs, lower legs and feet were generated from the approved pet references, then extracted and registered to the existing bodies. Llama uses four upper/lower leg/hoof chains.

This is an intermediate option retaining the earlier flattened expression heads. The latest requested combination, including separate head shape, ears, eyes, mouth and nose, is in **../rig-64-modular/**. Use that set for the current handoff.

This intermediate exceeds the original 12-part limit (16/16/17/17 parts). Neutral rigs and the existing whole-head expressions were exported only in an isolated validation process with MAXP24 and C syntax checked; firmware was not changed. Build script: `tools/art/build_pet_rigs_articulated.py`.
