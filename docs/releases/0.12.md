## PurpleMonkey 0.12

For the FM-1s with the newer flash chip. Nothing changes in how PurpleMonkey plays.

### Fixed

- **FM-1s sold late 2026 (the M-VAVE logo printed on the front) can take updates.** These units carry a different
  1 MiB flash chip (JEDEC id 0xB36014; the older units have a Puya part, 0x856014). PurpleMonkey 0.10 and 0.11 knew
  only the older chip, so on a newer unit they ran without the flash: the instrument played, but the update entry
  stayed shut and every installer stopped "after 0 requests". 0.12 accepts both chips. From ChoralRoot 0.29.1,
  which found and fixed this first.
- **A slow flash erase no longer crashes.** The flash driver gave up waiting for an erase after 500 ms (10 ms for
  a write) and went back to running from the flash while the chip was still busy, which crashes. It now waits
  until the chip is done: a slow finish counts as success, and a chip still busy after 2 s (50 ms) is reset
  rather than read. This matters during an update, when PurpleMonkey writes the new package to the flash. The fix
  is Julius Vitkauskas's, from [felucca-bsp](https://github.com/hugelton/felucca-bsp) (#12), as RemoteFM1 0.3.4
  took it; treating a slow finish as success is PurpleMonkey's own choice.

**The newer chip has not been tried on hardware here**: the units we have all carry the older one. 0.12 was
built and tested on the computer (the host tests and a model of the chip's timing), not installed on an FM-1 with
the newer chip.

### If your FM-1 has the newer chip and runs PurpleMonkey 0.10 or 0.11

It cannot take 0.12 over USB (the installers' update entry is the part that stays shut). The way out is the
chip's own boot mode: hold OCT-, OCT+ and HOME for 5 s (the countdown, then "UBOOT"; this works on those units too),
restore M-VAVE's V15 with
[MvaveFM1Unbricker](https://github.com/Quixotic7/MvaveFM1Unbricker) (`restore`, with `--i-know` while it does not
know the chip's id), then install 0.12 over V15 with the web installer as on any unit. Details:
`docs/INSTALL-COMPAT.md`, "A second flash chip".

Installing over 0.11 on an older unit needs nothing special: PurpleMonkey stores nothing.
